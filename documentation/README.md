# Documentation

This folder centralises all project documentation — from design decisions to user guides.

## Suggested Contents

| File / Folder | Description |
|---------------|-------------|
| `requirements/` | System and sub-system requirements |
| `design_decisions/` | ADRs (Architecture Decision Records) |
| `datasheets/` | Component datasheets and reference manuals |
| `user_guide/` | Assembly instructions, setup guide, user manual |
| `reports/` | Test reports, simulation results, review notes |
| `images/` | Photos, renders, diagrams |

## Documentation Standards

- Use **Markdown** for all text documents
- Name files with lowercase and underscores (e.g., `power_supply_design.md`)
- Keep datasheets in `datasheets/` with the part number in the filename
- Log every major design decision in `design_decisions/` as an ADR
