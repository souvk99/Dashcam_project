Hardware Architecture & Subsystem Specification (Sheet 1)

System Objective: Ultra-low-cost, battery-buffered automotive vision streaming prototype using Luckfox Pico Mini B (RV1103 SoC, 64MB DDR2, 128MB SPI NAND) and SmartSens SC3336 3MP sensor.

1. Functional Subsystem Overview

Subsystem Component Selection Engineering Specification
Vision Processor Luckfox Pico Mini B (RV1103 SoC, 64MB DDR2, 128MB SPI NAND) ARM Cortex-A7 @ 1.2GHz + RISC-V co-processor, 64MB DDR2, built-in ISP 3.2, HW H.264/H.265 VPU.
Optical Sensor SmartSens SC3336 3MP MIPI CSI-2 2304x1296 @ 30fps, 2-lane MIPI D-PHY, 98.3 Deg wide-angle lens, high SNR low-light automotive profile.
Non-Volatile Storage 128MB SPI NAND Flash (Onboard) Zero SD card topology. Houses U-Boot, Linux kernel, Busybox rootfs, and RKMPI streamer daemon.
Wireless Network Realtek RTL8188EUS USB Dongle 802.11b/g/n 2.4GHz SoftAP mode, 150Mbps PHY rate, native in-kernel '8188eu' driver.
Power Management Injoinic IP5306 Synchronous PMIC 2.1A CC/CV LiPo charger, 5.0V @ 2.4A boost output, autonomous load-sharing, over/under voltage protection.
Input Pre-Regulator LM2596 DC-DC Step-Down Buck Steps down vehicle electrical rail (9V-16V nominal, transients up to 40V) to regulated 5.0V DC.

4. Passive Protection Schedule

Ref Des Component Value Package Functional Location & Engineering Purpose
