# Mechanicals

This folder contains all physical and mechanical design assets for the dashcam prototype.

## Structure

| Folder | Contents |
|--------|----------|
| `source/` | CAD files (STL, STEP, F3D, etc.), enclosure designs, mounting brackets |
| `simulation/` | FEA / thermal / vibration simulation files and results |

## Recommended Tools

- **CAD**: Fusion 360 / FreeCAD / SolidWorks
- **Slicing** (3D print): Ultimaker Cura / PrusaSlicer
- **Simulation**: Ansys / SimScale / FreeCAD FEM

## Design Considerations

- Compact form factor for windshield mounting
- Heat dissipation for sustained recording
- Vibration resistance
- Cable management and port access
